# 🎓 College Appointment System

> **One-liner:** Backend API where students book appointments with professors. Professors set availability; students authenticate, view slots, book.

**GitHub:** [sshivanshg/college_system](https://github.com/sshivanshg/college_system)

## Features
- User auth — student + professor roles
- Role-based access
- Professor availability management
- Student appointment booking
- Professor cancel appointments

## Stack
- Node.js + Express
- MongoDB + Mongoose
- JWT auth
- Postman collection
