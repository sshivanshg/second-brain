# 🛠️ DevHelp — v0.5 Capabilities & Validation

Companion to [[DevHelp]]. Captures the unreleased v0.5 expansion: **18 features across two rounds**, all built, unit-tested, and (where the environment allowed) validated end-to-end. Test count went **82 → 141**.

## Capability expansion (the 18)

### Round 1 — core advancement
1. **`--json`** — machine-readable run payload (status, detected, steps, failures, verify); silent task renderer so stdout stays clean.
2. **System package-manager detection** (`platform.ts`) — apt / dnf / yum / pacman / zypper / apk / brew, with a logical→package map (`openssl-dev`, `pkg-config`, `python3`, `build-tools`).
3. **`--fix` auto-recovery** — recovery rules carry `systemDeps`; a failed native build installs the dep and **retries once**. (Xcode CLT stays hint-only — installer is interactive.)
4. **`--write-lock`** → `.devhelp.lock` — pins resolved runtime versions + package manager + install commands.
5. **`.devhelp.yml` recipes** — repo declares `postInstall:` steps and `dev`/`test`/`build` overrides; dependency-free YAML-subset parser.
6. **`--with-services`** — opt-in `docker compose up -d --wait`; default stays surface-only.
7. **DB provisioning** — under `--with-services`: Prisma `migrate deploy` (+ seed).
8. **`--verify`** ⭐ — runs tests + boots the dev server, polls the URL, kills it; non-zero exit on failure. Makes the core promise measurable per-run.
9. **`devhelp doctor`** — read-only diagnosis of an existing checkout (no clone/mutation).

### Round 2 — hardening + breadth
10. **Real-repo validation** — 21 cloned repos, 0 crashes; real e2e `--verify` on a live express app.
11. **Compose v1 fallback** — `docker compose` (v2, `--wait`) → `docker-compose` (v1, no `--wait`).
12. **doctor version-mismatch** — `⚠` + non-zero exit when an installed version disagrees with what the repo wants (compared at the granularity of the wanted spec).
13. **`.devhelp.lock` drift** — warns when detection diverges from a committed lock.
14. **Multi-ORM DB provisioning** — Prisma, **Drizzle** (`drizzle-kit migrate`), **Django** (`manage.py migrate` with venv/poetry/uv/pipenv prefix), **Rails** (`db:prepare`). Ecto already covered by Phoenix `mix ecto.setup`.

### Round 3 — the remaining deferred items
15. **`--vscode`** — generate `.vscode/launch.json` (node-terminal for dev cmd, debugpy for Django/FastAPI/Flask); never overwrites.
16. **`--secrets`** — populate `.env` from 1Password (`op inject` on `op://` refs) or Doppler (`doppler secrets download`).
17. **`devhelp mcp`** — hand-rolled MCP (JSON-RPC 2.0 over stdio) server exposing `detect` + `doctor`. **No new dependency.**
18. **Windows groundwork** — cross-platform probing (`where` vs `command -v`), per-platform shell pick, and an up-front WSL/Git-Bash guard instead of cryptic per-step failures.

## Architecture (module map)
| Module | Role |
|---|---|
| `src/cli.ts` | Commander entry — flags + `doctor`/`mcp` subcommands |
| `src/offline.ts` | Orchestrator: clone → detect → recipe → listr task list → verify → summary; all installers; `doctor`; `runDoctor`/`diagnoseProject` |
| `src/detect.ts` | 29-ecosystem detection (runtimes, pm, frameworks, prisma, services, migrations) |
| `src/platform.ts` | System pkg-manager detection + cross-platform probing + shell pick |
| `src/recovery.ts` | Deterministic failure→fix rules (with `systemDeps`) |
| `src/verify.ts` | Test run + dev-server probe/kill (pure `isServerUp`/`pollUrl`) |
| `src/lockfile.ts` | `.devhelp.lock` build / read / drift diff |
| `src/recipe.ts` | `.devhelp.yml` parser |
| `src/vscode.ts` | launch.json generation |
| `src/secrets.ts` | 1Password / Doppler detection + command building |
| `src/mcp.ts` | MCP stdio JSON-RPC server |
| `src/run-log.ts`, `versions.ts`, `version-managers.ts` | run logs, version normalization + security gate, mise/asdf/fnm/volta |

Design rule held throughout: **safe-by-default** — every outward/destructive action (`--with-services`, `--fix`, `--verify`, `--secrets`) is opt-in; DB uses non-destructive `migrate deploy`, never `migrate dev`.

## Validation receipts
- **21 real cloned repos** (astro, cal.com, django, next.js, supabase, react…): **0 crashes** with every flag enabled (dry-run + JSON).
- **Real end-to-end `--verify`**: express installed for real → `npm test` passed → dev server booted and answered at `http://localhost:3000` → process killed (no port leak). Failure path confirmed to exit 1.
- **MCP**: real piped JSON-RPC handshake (initialize → tools/list → `doctor` call) returns clean structured results.
- **141 tests pass**, `tsc --noEmit` clean.

### 🐛 Bug found & fixed during validation
`nvm use lts/*` crashed under **zsh** (the macOS default) with `zsh: no matches found: lts/*` — the `*` glob-expanded before nvm saw it, breaking setup for *any* Node repo without a pinned version. Fixed by quoting version tokens; regression-guarded in `test/shell-quoting.test.ts`.

## Deferred (honest)
- **Full native Windows** — groundwork + guard shipped and unit-tested, but **no Windows host to validate the install path** → stays "WSL/Git-Bash recommended."
- **Live `--with-services`** — no Docker daemon in the build env → compose-up + migrations are unit/dry-run tested only, not run against a real container.
- **JetBrains run-config generation** — the IDE analog of `--vscode`, not yet built.
