## How this works
Every project note has frontmatter like:
```yaml
categories: [fullstack, ai-ml]
audience: [startup]
```

The Dataview blocks below each MOC reads those fields and lists matching projects. **No manual updating.** Just tag a new project correctly and it shows up.
