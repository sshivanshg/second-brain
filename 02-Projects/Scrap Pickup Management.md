# ♻️ Scrap Pickup Management System

> **One-liner:** Backend for managing scrap pickup & recycling services — booking, real-time driver tracking, time slots. Node.js + MongoDB.

**GitHub:** [sshivanshg/scrapping_backend](https://github.com/sshivanshg/scrapping_backend)

## Features
**User app**
- Scrap pickup booking with time slots + address
- Minimum quantity enforcement (10kg)
- Real-time tracking — live driver location on a map

**(Likely) driver + admin** sides for assignment and fulfillment.

## Stack
- Node.js + Express
- MongoDB
- Real-time location (sockets / polling)
