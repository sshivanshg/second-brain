# Spaced repetition beats rereading

> Active retrieval at increasing intervals encodes memory far more effectively than passive review.

## Context
This is the foundational reason note-taking systems work — but only if you *revisit* notes, not just write them. A second brain that's write-only is just a graveyard.

## Details
- Rereading creates an illusion of competence (familiarity ≠ recall).
- Effortful retrieval — even when it fails — strengthens memory traces.
- Optimal intervals expand over time: 1 day → 3 days → 1 week → 1 month.
