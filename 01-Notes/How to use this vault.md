# How to use this vault

> Your second brain is only useful if you actually use it. Lower the friction.

## The 3 rules

### 1. Capture without filtering
When an idea hits, drop it in `00-Inbox` or today's daily note. Don't decide where it goes. Don't format it. Just capture.

### 2. One note = one idea
When you process inbox items into `01-Notes`, each note should hold a single atomic idea. Title it as a **claim**, not a topic:
- ❌ "Productivity"
- ✅ "Time-blocking beats to-do lists for deep work"

### 3. Always link
Every new note must link to at least 2 other notes using `[[double brackets]]`. No links = orphan note = useless.

## The daily workflow
1. Open Obsidian → today's daily note auto-opens
2. Capture thoughts, tasks, learnings throughout the day
3. End of day: scan the note, ask "anything worth promoting to an atomic note?"

## The weekly workflow
Every Sunday (or whenever):
1. Open `Templates/Weekly-Review`, create the week's review
2. Process every note in `00-Inbox`: trash it, file it, or turn it into an atomic note
3. Update active projects in `02-Projects`
4. Set next week's top 3 priorities

## Tagging strategy
Tags are search aids, not folders. Use sparingly:
- `#status/seedling` (rough), `#status/growing`, `#status/evergreen` (polished)
- `#type/book`, `#type/meeting`, `#type/project`
- Topic tags only if you'd actually search for them

## Linking patterns
- `[[Note]]` — standard link
- `[[Note|custom display text]]` — link with renamed display
- `[[Note#Heading]]` — link to a specific section
- `![[Note]]` — embed the entire note inline

## When in doubt
- Lost? → [[Home]]
- Don't know where to file? → `00-Inbox`
- Note feels too big? → split it into atomic notes
- Note feels too small? → that's fine, atomic is good
