# Inbox processing checklist

> Run this weekly. Goal: empty inbox, every capture has a home.

## For each note in `00-Inbox`

Ask in order:
1. **Is it still relevant?** → if no, delete
2. **Is it actionable now?** → if yes, do it (2-min rule) or add to a project
3. **Is it a single atomic idea?** → file in `01-Notes`, title as a claim, add 2+ links
4. **Is it reference material?** → file in `04-Resources`
5. **Is it part of an ongoing area?** → file in `03-Areas`
6. **Otherwise** → archive or delete

## Promotion criteria (inbox → atomic note)
A capture deserves to become an atomic note if:
- [ ] It's a single, distinct idea
- [ ] You can title it as a claim
- [ ] It connects to at least 2 existing notes
- [ ] Future-you would want to find it again

## Anti-patterns
- ❌ Letting inbox grow past 30 notes
- ❌ Keeping captures "just in case" forever
- ❌ Atomic notes with no outgoing links
- ❌ Multiple ideas crammed into one note
