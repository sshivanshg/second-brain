# ✅ Tasks dashboard

> Every checkbox across the vault, rolled up. Powered by the **Tasks** plugin. Write tasks anywhere as `- [ ] do thing 📅 2026-05-30` and they appear here.

## 🔴 Overdue
```tasks
not done
due before today
sort by due
short mode
```

## 📅 Due today
```tasks
not done
due today
short mode
```

## 🗓️ Due this week
```tasks
not done
due after yesterday
due before in 7 days
sort by due
short mode
```

## 📌 No due date (someday / backlog)
```tasks
not done
no due date
path does not include Templates
group by path
short mode
limit 30
```

## ✔️ Recently completed
```tasks
done
sort by done reverse
limit 10
short mode
```

---

## How to write good tasks
- `- [ ] Ship UPI disbursement 📅 2026-06-15` — due date
- `- [ ] Call investor ⏫` — high priority (⏫ high, 🔼 medium, 🔽 low)
- `- [ ] Review PR 🔁 every week` — recurring
- `- [ ] Fix bug #arth-saathi` — tag for filtering

Put tasks **in the relevant project note or daily note** — never maintain a separate to-do list. This dashboard aggregates them automatically.
